Block AI Content

When an AI-labelled image is found

How strict

Off: only formal "this is AI" labels (the IPTC/C2PA disclosures the EU AI Act's marking rules point to).
On: also catches leftovers from tools such as Stable Diffusion and ComfyUI, and Google's "Made with Google AI" credit line.

Sites to leave alone

One website per line, e.g. example.com. Covers its subdomains too.

What this can and can't do

  • Can: spot images that carry a machine-readable "made by AI" label in their file data: C2PA Content Credentials or the IPTC "digital source type" tag. OpenAI, Adobe Firefly, Google, Microsoft and others add these.
  • Can't: spot AI images that carry no label. Many sites strip file data when you upload, which removes the label too.
  • Can't: read invisible watermarks (e.g. Google SynthID). Only the vendor's own tools can check those.
  • Can't: detect AI-written text. Nobody can do that reliably.

Privacy: the extension downloads each image a second time to read its file data. Nothing is sent anywhere else, and nothing is logged.
